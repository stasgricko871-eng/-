# 🎮 Как запустить игру вне AI Studio

## Почему при двойном клике по `index.html` был белый экран?
1. **Файлы TypeScript (`.tsx`)**: исходный `index.html` содержит строку `<script src="/src/main.tsx">`. Обычные браузеры не могут читать TypeScript напрямую — его должен скомпилировать сборщик (Vite).
2. **Блокировка безопасности браузеров (CORS на `file:///`)**: современные браузеры (Chrome, Edge, Opera, Firefox) блокируют загрузку любых скриптов-модулей, если файл открыт простым двойным кликом с диска как `file:///C:/...`.

---

## ✅ Как правильно запустить игру:

### Вариант 1: Самый простой (в 1 клик на Windows)
Просто дважды кликните по файлу **`start_game.bat`**.
* Он автоматически проверит зависимости, запустит локальный сервер и сам откроет игру в вашем браузере по адресу `http://localhost:3000`.

*(Для Linux / Mac: запустите в терминале `./start_game.sh`)*

---

### Вариант 2: Через командную строку / терминал (Developer Mode)
Откройте терминал (PowerShell или Командную строку) в папке с игрой и выполните:
```bash
npm install
npm run dev
```
После этого перейдите по ссылке, которую покажет терминал (обычно **`http://localhost:3000`** или `http://localhost:5173`).

---

### Вариант 3: Запуск готовой production-версии
Если хотите запустить собранную оптимизированную сборку:
```bash
npm run build
npm run preview
```
Или:
```bash
npx tsx serve_game.ts
```

---

### Вариант 4: Без Node.js (через Python)
Если на компьютере установлен Python:
```bash
python -m http.server 3000 --directory dist
```
И откройте `http://localhost:3000` в браузере.

---

## 📱 Запуск на телефоне через Termux (Android)

1. Установите Node.js в Termux:
```bash
pkg update && pkg install nodejs-lts
```
2. Разрешите доступ к файлам телефона:
```bash
termux-setup-storage
```
3. Перейдите в папку с игрой (например, если скачали в Загрузки):
```bash
cd /sdcard/Download/<имя_папки>
```
4. Запустите игру:
```bash
sh start_termux.sh
```
*(Или вручную: `npm install` затем `npm run dev -- --host`)*
5. Откройте любой браузер на телефоне (Chrome, Brave, Яндекс) и перейдите по адресу:
👉 **`http://localhost:3000`**
