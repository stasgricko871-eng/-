# 🎨 Спрайт-шит Deltarune: Meow Meow Last Chance

Файл спрайт-шита находится здесь:
- **`/textures/spritesheet.png`** (для удобного просмотра и замены в корне)
- **`/public/textures/spritesheet.png`** (откуда игра загружает картинку в браузере)

---

### Разметка сетки (Grid Layout):
* **Размер одного спрайта**: 16 × 16 пикселей.
* **Общий размер листа**: 64 × 64 пикселей (4 колонки × 4 ряда).

```
        Колонка 0 (X: 0)       Колонка 1 (X: 16)      Колонка 2 (X: 32)      Колонка 3 (X: 48)
Ряд 0:  [ Розовая (Покой) ]    [ Розовая (Шаг 1) ]    [ Розовая (Шаг 2) ]    [ Розовая (Бросок) ]
Ряд 1:  [ Кибер-Мышка 1 ]      [ Кибер-Мышка 2 ]      [ Бомба Фетуса ]       [ Бомба (Фрейм 2) ]
Ряд 2:  [ Взрыв (Центр) ]      [ Взрыв (Горизонт.) ]  [ Взрыв (Вертикал.) ]  [ Вспышка взрыва ]
Ряд 3:  [ Резерв / Предметы ]  [ Резерв ]             [ Резерв ]             [ Резерв ]
```

---

### Как легко заменить текстуры:
1. Открой файл `textures/spritesheet.png` в любой программе для рисования пиксель-арта (**Aseprite**, **Photoshop**, **Paint.NET**, **GIMP** или даже в обычном онлайн-редакторе).
2. Нарисуй своего персонажа или мышек в соответствующих квадратах 16×16.
3. Сохрани файл обратно как `textures/spritesheet.png` и `public/textures/spritesheet.png`.
4. Игра автоматически отрисует твои новые спрайты!
